# Doki Doki Fruit Catch

Download all five Unity-Source ZIP files and extract them into the same folder. Open that folder in Unity 6000.6.6f1. It includes Assets, Packages, ProjectSettings, ESP32 firmware and the MediaPipe camera helper. The Google Sheets URL is omitted and must be configured locally in Assets/Scene/GoogleSheetsReporter.cs.

For the WebGL version download the repository as ZIP, extract it, and run Start-Game.cmd with Python 3 installed. The game opens at http://localhost:8766/. It sends results to the configured score service. For camera controls, download CameraBridge.zip from the game sensor panel.
